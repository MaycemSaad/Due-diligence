## Overview

**Due Diligence** is a smart web application designed to automatically extract relevant information from complex documents — financial reports, legal contracts, financial statements, and more.

It combines **NLP**, **Generative AI**, and **interactive visual analytics** to support analysts in decision-making.

---

## Project Objectives

| Objective | Description |
|---|---|
| **Document Extraction** | Automatic extraction and analysis of textual information from complex documents |
| **Semantic Parsing** | Implementation of semantic parsing using NLP and LangChain |
| **Report Generation** | Automatic generation of detailed PowerPoint reports |
| **Advanced Analysis** | Document classification, risk scoring, and RAG chatbot with LLMs and Human-in-the-Loop |
| **User Interface** | Streamlit-based interface for visualization and document search |
| **Analytics Dashboard** | Dash/Plotly dashboard for performance monitoring and key indicators |
| **Data Storage** | Structured data persistence with MongoDB |
| **Financial Forecasting** | Integration of time series forecasting models for financial trend analysis |
